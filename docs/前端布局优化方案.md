# AstraCoreAI 前端布局优化方案

> 对标标准：Claude.ai / ChatGPT / Perplexity  
> 原则：布局契约优先于视觉装饰，不用任何 magic number，单一数值单一出处

---

## 一、现状问题清单

| # | 问题 | 严重程度 | 根因 |
|---|------|---------|------|
| P1 | 消息列表与输入框宽度不对齐（差约 220px） | 严重 | 两处用了不同策略：消息用 `padding: 14%`，输入用 `maxWidth: 1040 + padding: 24px` |
| P2 | Header 左侧完全空白，导航栏靠右贴边 | 中等 | `justify-content: flex-end`，无 Logo 区 |
| P3 | 非聊天页面（Skills/Memory/RAG/System）Header 无品牌标识 | 中等 | Brand Logo 只在 Sidebar，Sidebar 在非聊天页不存在 |
| P4 | 聊天三栏结构用 `margin` 魔法值维护，脆弱 | 中等 | Bubble 组件不原生支持双侧固定占位 |
| P5 | 无间距 token 系统，数值散落各处 | 轻微 | 直接写内联 style，无统一 CSS 变量 |
| P6 | Sidebar 固定 300px 宽，窗口缩小时挤压消息区 | 轻微 | 无响应式断点处理 |

## 二、目标布局结构

### 2.1 整体页面结构

```
AppShell [100vh, flex-column]
├─ GlobalHeader [64px, flex-row, 三段式]
│  ├─ HeaderLeft  [200px, brand logo + name]
│  ├─ HeaderCenter [flex:1, NavMenu 水平居中]
│  └─ HeaderRight [200px, ThemeToggle + 其他工具]
└─ RouteContent [flex:1, overflow:hidden]
   └─ <Outlet />
```

### 2.2 聊天页结构

```
ChatPage [flex-row, 100%]
├─ Sidebar [260px, 可折叠]
│  ├─ SidebarHeader [Logo 图标 + 折叠按钮]
│  ├─ NewConversationButton
│  ├─ SearchInput
│  └─ ConversationList [scroll]
└─ ChatMain [flex:1, flex-column]
   ├─ MessageScrollArea [flex:1]
   │  └─ MessageListContainer [maxWidth: CONTENT_MAX_WIDTH, margin: 0 auto, width: 100%]
   │     └─ MessageRow (每条消息)
   │        ├─ AIAvatarSlot  [width: AVATAR_SLOT_W, flex-shrink: 0]
   │        ├─ ContentSlot   [flex: 1, min-width: 0]
   │        └─ UserAvatarSlot [width: AVATAR_SLOT_W, flex-shrink: 0]
   ├─ AlertBanner [conditional]
   └─ InputPanel [flex-shrink: 0]
      └─ InputContainer [maxWidth: CONTENT_MAX_WIDTH, margin: 0 auto, width: 100%]
         ├─ Toolbar
         └─ Sender
```

### 2.3 聊天三栏布局契约（核心）

```
MessageRow [display: flex, width: 100%, gap: AVATAR_GAP, padding: MSG_VERTICAL_PADDING 0]
├─ AIAvatarSlot
│  ├─ 宽度: AVATAR_SLOT_W (= avatar 32px + gap 12px = 44px)
│  ├─ 内容: AI 消息时显示 Avatar，用户消息时为空占位
│  └─ 规则: 永远不允许消息气泡进入此区域
├─ ContentSlot
│  ├─ 宽度: flex: 1, min-width: 0（自动填充剩余空间）
│  ├─ AI 消息: 左对齐，内容从左铺开
│  ├─ 用户消息: 右对齐，气泡从右向左扩展
│  └─ 规则: 内容不论多长，左边界不得超过 AIAvatarSlot 右边缘，右边界不得超过 UserAvatarSlot 左边缘
└─ UserAvatarSlot
   ├─ 宽度: AVATAR_SLOT_W (= 44px)
   ├─ 内容: 用户消息时显示 Avatar，AI 消息时为空占位
   └─ 规则: 永远不允许消息气泡进入此区域
```

## 三、间距 Token 系统

在 `global.css` 中定义，全局统一引用，避免魔法数字：

```css
:root {
  /* ── 内容列宽度 ────────────────────────────────── */
  --content-max-width: 860px;      /* 消息列表 + 输入框共用的最大宽度 */
  --content-padding-x: 24px;       /* 内容列左右内边距（用于窄屏） */

  /* ── 聊天三栏 ──────────────────────────────────── */
  --avatar-size: 32px;             /* Avatar 组件尺寸 */
  --avatar-gap: 12px;              /* Avatar 与消息气泡的间距 */
  --avatar-slot-width: 44px;       /* = avatar-size + avatar-gap，两侧固定占位宽度 */

  /* ── 消息行 ────────────────────────────────────── */
  --msg-row-gap-y: 16px;           /* 消息行之间的间距 */
  --msg-padding-y-top: 24px;       /* 消息列表顶部内边距 */
  --msg-padding-y-bottom: 16px;    /* 消息列表底部内边距 */

  /* ── 输入区 ────────────────────────────────────── */
  --input-panel-padding-x: 0;      /* 输入区横向 padding（由 InputContainer 的 maxWidth 控制） */
  --input-panel-padding-y-top: 8px;
  --input-panel-padding-y-bottom: 20px;

  /* ── Header ────────────────────────────────────── */
  --header-height: 64px;
  --header-side-width: 200px;      /* HeaderLeft / HeaderRight 固定宽度 */

  /* ── Sidebar ───────────────────────────────────── */
  --sidebar-width: 260px;
  --sidebar-width-collapsed: 0px;
}
```

## 四、各区域布局契约

### 4.1 GlobalHeader

```
布局: flex-row, align-items: center, height: var(--header-height)
├─ HeaderLeft  [width: var(--header-side-width), flex-shrink: 0]
│  规则: Logo 图标 + 文字，overflow: hidden，不换行
├─ HeaderCenter [flex: 1, display: flex, justify-content: center]
│  规则: NavMenu 不得撑破容器；items 过多时改为 dropdown
└─ HeaderRight [width: var(--header-side-width), flex-shrink: 0, justify-content: flex-end]
   规则: 主题切换 + 未来可放用户头像；从右向左排列
```

### 4.2 Sidebar

```
布局: flex-column, width: var(--sidebar-width), flex-shrink: 0
├─ SidebarHeader [padding: 16px, flex-row, align-items: center]
│  规则: Logo icon + 折叠 toggle button；折叠时只显示 icon
├─ ActionArea [padding: 0 12px 10px]
│  - NewConversationButton: block, size=large
│  - SearchInput: width: 100%
├─ ConversationList [flex: 1, overflow: hidden]
│  规则: 内部滚动；分组后各组 header sticky
└─ 折叠状态
   - 宽度: 0（配合 CSS transition: width 0.2s）
   - 内容: visibility: hidden（保留 DOM，避免反复 mount）
```

### 4.3 MessageScrollArea

```
布局: flex: 1, overflow: hidden
└─ AppScrollArea [height: 100%]
   └─ 顶部哨兵 [height: 1px, 用于 IntersectionObserver 触发 loadMore]
   └─ MessageListContainer
      [max-width: var(--content-max-width), margin: 0 auto, width: 100%]
      [padding: var(--msg-padding-y-top) var(--content-padding-x) var(--msg-padding-y-bottom)]
      规则:
        - maxWidth 约束内容列宽度，两侧空白由 margin: auto 均分
        - content-padding-x 保证窄屏时不贴边
        - 所有 MessageRow 在此容器内，无例外
```

### 4.4 MessageRow（聊天三栏）

```
布局: flex-row, align-items: flex-start, gap: 0
       width: 100%, margin-bottom: var(--msg-row-gap-y)

├─ AIAvatarSlot [width: var(--avatar-slot-width), flex-shrink: 0, padding-right: var(--avatar-gap)]
│  - AI 消息: <Avatar size={32} icon={<RobotOutlined />} />
│  - 用户消息: 空 div（保持占位，宽度不变）
│
├─ ContentSlot [flex: 1, min-width: 0, display: flex, flex-direction: column]
│  - AI 消息: align-items: flex-start
│    └─ <AssistantContent /> 自然展开，宽度随内容，max-width: 100%
│  - 用户消息: align-items: flex-end
│    └─ 气泡 div: 自然宽度，最大宽度 80%（防止短消息撑满）
│         内容: pre-wrap, word-break: break-word
│
└─ UserAvatarSlot [width: var(--avatar-slot-width), flex-shrink: 0, padding-left: var(--avatar-gap)]
   - 用户消息: <Avatar size={32} icon={<UserOutlined />} />
   - AI 消息: 空 div（保持占位，宽度不变）
```

**为什么放弃 Bubble.List 的 roles avatar 机制：**  
`Bubble` 组件只支持单侧头像，无法在消息行两端同时保留固定占位区域。当前用 `marginLeft/Right: 44` 的 workaround 在有 footer 时依赖 `ant-bubble-content-wrapper` 的内部 flex 实现，存在 antd/x 版本升级破坏的风险。专业做法是完全自定义 MessageRow，用 `Bubble` 只渲染内容（不传 avatar prop），头像区单独管理。

### 4.5 InputPanel

```
布局: flex-shrink: 0, border-top, padding: var(--input-panel-padding-y-top) 0 var(--input-panel-padding-y-bottom)

└─ InputContainer
   [max-width: var(--content-max-width), margin: 0 auto, width: 100%]
   [padding: 0 var(--content-padding-x)]
   规则:
     - 与 MessageListContainer 使用完全相同的 maxWidth 和 padding-x
     - 保证消息列表左边界 = 输入框左边界（视觉对齐）
   ├─ Toolbar [flex-row, flex-wrap, gap: 6px, margin-bottom: 8px]
   └─ Sender [width: 100%]
```

## 五、实现任务分解

### Task 1：建立 CSS Token 系统
**文件：** `src/global.css`  
添加上述所有 CSS 自定义属性到 `:root` 和 `html[data-theme='dark']`。

### Task 2：重构 GlobalHeader（三段式布局）
**文件：** `src/layouts/AppShell.tsx`  
- 将 `justify-content: flex-end` 改为三段式 flex（Left / Center / Right）
- 左段：Logo 图标 + "AstraCoreAI" 文字（从 ConversationSidebar 移入）
- 中段：NavMenu 居中
- 右段：ThemeToggle（未来可放用户头像）

### Task 3：重构 MessageRow 为自定义三栏组件
**文件：** `src/features/chat/components/ChatMain.tsx`  
- 移除 `Bubble.List` 的 `roles.avatar`，改为自定义 MessageRow 组件
- MessageRow 实现完整三栏结构（AIAvatarSlot / ContentSlot / UserAvatarSlot）
- 保留 `Bubble` 组件仅用于渲染消息内容（不传 avatar，保留 variant/loading）
- 用户气泡最大宽度限制为 ContentSlot 的 80%

### Task 4：统一 MessageListContainer 与 InputContainer 宽度
**文件：** `src/features/chat/components/ChatMain.tsx`  
- MessageListContainer: `max-width: var(--content-max-width); margin: 0 auto; padding: ... var(--content-padding-x)`
- InputContainer: 同上，完全相同的 maxWidth 和 padding
- 移除原来消息列表的 `padding: '20px 14%'`（Bubble.List 的 style prop）

### Task 5：Sidebar 折叠支持
**文件：** `src/layouts/AppShell.tsx` 或 `src/features/chat/pages/ChatPage.tsx`  
- 添加 `sidebarCollapsed` 状态
- Sidebar width 由 CSS transition 控制（260px ↔ 0px）
- Header Left 区域与 Sidebar 宽度解耦（不再依赖 Sidebar）

## 六、验证清单

完成每个 Task 后需验证：

- [ ] TypeScript 编译无报错（`tsc --noEmit`）
- [ ] 消息列表左边界 = 输入框左边界（用浏览器开发者工具量像素）
- [ ] AI 消息头像始终贴左，用户消息头像始终贴右，跨消息类型时占位存在
- [ ] 消息气泡在任何情况下不进入头像占位区（短消息/长消息/代码块/表格均验证）
- [ ] Header 三段在 1280px / 1440px / 1920px 下对齐正常，不挤压
- [ ] 深色/浅色主题切换后，所有区域颜色正确
- [ ] 窗口缩小至 900px 时，消息列表和输入框仍有 `content-padding-x` 的最小边距，不贴边

---

## 七、不做的事（本次范围外）

- 响应式 Sidebar（移动端抽屉式）：留待后续
- 消息搜索 / 跳转：功能需求，非布局问题
- 虚拟滚动（Virtual List）：性能优化，消息量超过 500 条再考虑
- 动画/过渡效果（消息出现动画等）：视觉增强，布局稳定后再叠加
