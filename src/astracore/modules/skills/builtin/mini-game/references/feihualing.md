# 飞花令

用户选飞花令 / 诗词接龙时加载本文件。

---

## 快速起手

> 🌸 飞花令～ 默认主题字「**月**」。
>
> 我先来：**举头望明月，低头思故乡**。
>
> 你来一句含「月」的古诗词。

---

## 规则

- AI 指定一个**主题字**（如"花""月""春""风""山""水"）
- 双方轮流说出含该字的**古诗词原句**，含字位置不限（首 / 中 / 尾均可）
- 重复 / 想不出 / 引非古诗词 → 输

---

## 判定标准

| 接受 | 拒绝 |
|---|---|
| 唐诗、宋词、元曲、明清诗词 | 现代诗、流行歌词、改编版本 |
| 诗经、楚辞 | 古文（《滕王阁序》《岳阳楼记》等散文片段） |
| 整句（至少 5 字） | 拆字孤词（"月"单字、"花儿"两字） |
| 常用熟句 | 自创 / 不可考的句子 |

### 用户引错时的处理

- **错字 / 错版本**（如"床前明月光"写成"床前看月光"）→ 提示正确版本，**不直接判负**："常见的版本是 X，我们就用这一句往下走"
- **作者记错**（如把杜甫的诗记成李白）→ 不影响接龙，可补一句"这其实是 X 的诗"
- **风马牛不相及**（用户给了一句不含主题字的）→ "这句没有「月」字哦，再想一句？"
- **半句**（"明月几时有"）→ 接受，常用半句也算

---

## AI 出题策略

- 不堆生僻冷门——从课本级到稍冷门渐进
- 第一轮用最常见的（《静夜思》《水调歌头》等）建立信心
- 用户连续 3 句答对 → 开始用稍偏的句子（不到生僻程度）
- 用户卡住时**给提示**："试试李白的？" / "想想跟思乡有关的？"

### 主题字难度分级

| 难度 | 主题字示例 | 说明 |
|---|---|---|
| 入门 | 月、花、春、风、山、水、月、人 | 出现频率极高，候选千句 |
| 中等 | 雨、雪、云、酒、夜、归、心、客 | 候选数百 |
| 进阶 | 红、白、青、绿、香、影、寒、暖 | 候选较多但不直觉 |
| 挑战 | 梅、柳、雁、鸿、舟、笛、琴、剑 | 候选有限，考人 |

用户没指定主题字时默认从「入门」级随机挑 1 个；用户说"换个难的"时升一级。

## 状态追踪

- 当前主题字
- 已用诗句列表（含字位置不同也算重复——如两人都说"举头望明月"算重复）
- 双方轮次

---

## 卡住时的提示阶梯

1. 第一次卡住：方向提示（"试试边塞诗？" / "李白的诗里很多"）
2. 第二次卡住：作者 + 题材提示（"杜甫写月亮的有好几句，比如《月夜》"）
3. 第三次卡住：给前两个字（"X X 望……"）
4. 第四次仍卡 → 视为认输，AI 揭晓 + 问是否换主题字继续

---

## 变体

- **同字接龙**：每句的最后一字必须是下一句的第一字（叠加难度）
- **主题升级**：用户连胜 3 局 → AI 提议升一级主题字难度
- **接龙合作**：用户和 AI 不对抗，比赛凑齐 N 句含某字的诗词（适合学习场景）
- **主题字开放**：用户可指定主题字（如"问问辛弃疾词里有「醉」字的"）

## 主题字起手范句库（AI 出题参考）

### "月"
- 举头望明月，低头思故乡（李白·静夜思）
- 海上生明月，天涯共此时（张九龄·望月怀远）
- 明月几时有？把酒问青天（苏轼·水调歌头）
- 月落乌啼霜满天（张继·枫桥夜泊）

### "花"
- 春城无处不飞花（韩翃·寒食）
- 感时花溅泪，恨别鸟惊心（杜甫·春望）
- 落花人独立，微雨燕双飞（晏几道·临江仙）
- 桃花潭水深千尺（李白·赠汪伦）

### "春"
- 春眠不觉晓（孟浩然·春晓）
- 国破山河在，城春草木深（杜甫·春望）
- 春风又绿江南岸（王安石·泊船瓜洲）
- 红杏枝头春意闹（宋祁·玉楼春）

### "风"
- 大风起兮云飞扬（刘邦·大风歌）
- 风萧萧兮易水寒（《战国策》荆轲）
- 春风又绿江南岸（王安石·泊船瓜洲）
- 夜来风雨声（孟浩然·春晓）

### "山"
- 不识庐山真面目（苏轼·题西林壁）
- 山重水复疑无路（陆游·游山西村）
- 空山不见人（王维·鹿柴）
- 一览众山小（杜甫·望岳）

### "水"
- 水调歌头·明月几时有
- 流水落花春去也（李煜·浪淘沙）
- 抽刀断水水更流（李白·宣州谢朓楼饯别校书叔云）
- 沧海月明珠有泪（李商隐·锦瑟）

> 此库非穷举；AI 应根据自身知识灵活给出，不限于此清单。
