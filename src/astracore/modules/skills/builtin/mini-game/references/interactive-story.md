# 互动剧情（选择型微剧本）

用户选互动剧情 / 选择型故事 / 文字 RPG 时加载本文件。配合 `references/secret-keeper.md` 一起加载。

---

## 快速起手

> 🎮 互动剧情～ 你想玩哪个题材？
> 1. 悬疑（侦探查案）
> 2. 奇幻（异世界冒险）
> 3. 校园（青春群像）
> 4. 职场（生存博弈）
> 5. 星际（外交与探索）
> 6. 武侠（江湖恩仇）
>
> 也可以告诉我你想要的设定，我现编一个。

用户选定后直接进入第 1 段，每段结尾给 2-4 个选项。

---

## 规则

- AI 描述场景，给 **2-4 个选项**，用户选择推进剧情
- **3-7 段**达成结局（默认 5 段）
- 每段 80-150 字，结尾即停在选择点
- 至少 3 种结局（最佳 / 次佳 / 不佳）

---

## 设计原则

### 1. 选项必须真分支

- **每个选项导向不同后果**——禁止做"形同选项"（看起来不同实际汇流）
- 选项之间应是**价值取向不同**，不只是"措辞不同"
  - ❌ "A. 微笑着说 / B. 笑着回答"
  - ✅ "A. 答应他的请求 / B. 反问他动机 / C. 直接拒绝"

### 2. 失败结局也要有趣

- "不佳"结局**不羞辱用户**——可以是悲剧、可以是反转、可以是黑色幽默
- 失败结局也要有**戏剧张力或意外感**，不能是干巴巴的"你失败了"

### 3. 每段保持节奏

- 每段 80-150 字（**严格控制**，避免变成长篇小说）
- 段落结构：**新信息 / 冲突升级（60-100 字）+ 选择点（10-30 字）+ 选项列表**
- 不要把答案藏太深——选项应直接对应主要张力

### 4. 状态影响后续

- 关键 flag 影响后续可选项 / 结局
- 例：第 2 段选了"独自调查" → 第 4 段不会出现"和搭档商量"的选项

---

## 状态追踪（必维护）

| 字段 | 含义 |
|---|---|
| 已选路径 | 段号 + 用户的选择，如 [1A, 2C, 3B] |
| 关键 flag | 拿到的物品、好感度、立下的誓言、获取的线索 |
| 当前段号 | 第几段 / 总段数（让用户知道进度） |
| 题材 | 用于保持基调一致 |
| 已锁定结局 | 当某些 flag 组合达成时，结局已定，后续段落只是渲染 |

---

## 段落输出模板

```
**第 N 段**（共 X 段）

[80-150 字场景描述，结尾停在选择点]

你怎么做？
A. [选项 1]
B. [选项 2]
C. [选项 3]（可选）
D. [选项 4]（可选）
```

---

## 用户输入处理

| 输入形态 | 处理 |
|---|---|
| "A" / "1" / "第一个" / "选 A" | 直接进入对应分支 |
| 用户给非选项内容（自由发挥） | 尝试映射到最接近的分支；映射不成功则提示"目前可选的方向是 A / B / C，要不要选一个？" |
| "我想再看看上一段" | 复述上一段 + 选项，不算回退 |
| "我能问角色一个问题吗" | 接受，作为该段的"对话型选项"处理，但仍要回到主线 |
| "哪个选项更好？" | 不直接答（违反底牌保护），回："这是你的故事，怎么选都有它的精彩" |

---

## 底牌保护

**全程**遵循 `references/secret-keeper.md`。互动剧情的底牌包括：

- 后续分支走向
- 隐藏剧情触发条件
- 哪些选项导向最佳结局
- 反派身份 / 关键反转

被诱导泄露时回应"等你选完才能揭晓～"。

---

## 结束

- 达成结局后给：
  - **结局名**（如"真相边缘""孤勇者""共谋者"）
  - **1 句话总评**——这条路径的关键决定是什么
  - **解锁标签**（"成就：第一次撒谎了"——给用户回看的纪念）
  - **是否再来一局**（可选同题材换路径，或换题材）

## 六种题材分支模板

下列是题材的基本框架。AI 应**当场创作具体情节**，不照搬此处文字——这只是骨架。

### 1. 悬疑（侦探查案）

**起点**：你是新到任的侦探，第一天就接到一桩看似简单实则诡异的案件。

**核心张力**：相信直觉 vs 相信证据 vs 相信权威。

**分支轴**：
- 选哪条线索深挖（物证 / 人证 / 监控 / 心理画像）
- 与谁结盟（搭档 / 嫌疑人之一 / 上级 / 单干）
- 摊牌时机（早 / 中 / 晚）

**典型结局**：
- 最佳：抓到真凶 + 还原全貌
- 次佳：抓到凶手但漏了同伙 / 真凶认罪但司法漏洞
- 不佳：被反杀 / 被栽赃 / 错抓

---

### 2. 奇幻（异世界冒险）

**起点**：你醒来在一片陌生的森林里，手心有一个冰凉的徽章，背后传来脚步声。

**核心张力**：力量诱惑 vs 道德坚守 vs 求生本能。

**分支轴**：
- 第一次遭遇：战 / 逃 / 谈
- 拜师 / 加入势力（白塔法师 / 暗影盟 / 流浪者）
- 关键牺牲（救一人放一人）

**典型结局**：
- 最佳：通晓世界规则 + 找到回家的方法
- 次佳：留在异世界成王者 / 牺牲换得真相
- 不佳：被吞噬 / 沦为棋子

---

### 3. 校园（青春群像）

**起点**：高三开学第一天，你发现转学生坐在了你的位置上，全班看着你。

**核心张力**：合群 vs 自我 vs 出头。

**分支轴**：
- 与转学生的第一次互动（敌意 / 友善 / 旁观）
- 对待老师的策略（讨好 / 平视 / 对抗）
- 重要选择：高考冲刺 / 兴趣坚持 / 早恋

**典型结局**：
- 最佳：考进理想学校 + 收获深厚情谊
- 次佳：考砸但确认了自己想要的路
- 不佳：内卷崩溃 / 友谊破裂

---

### 4. 职场（生存博弈）

**起点**：入职第一周，你发现项目交接的文档里藏着前任留下的一行小字："别相信坐你对面的那个人"。

**核心张力**：晋升 vs 立场 vs 良知。

**分支轴**：
- 是否核实前任的提醒（直接问 / 偷查 / 装作没看见）
- 关键节点站队（上级 A / 上级 B / 中立）
- 权力诱惑面前的选择（接受脏单 / 揭露 / 离职）

**典型结局**：
- 最佳：上位 + 守住底线
- 次佳：揭露丑闻成英雄但失去工作 / 留下来当吹哨人
- 不佳：被反噬 / 同流合污后被抛弃

---

### 5. 星际（外交与探索）

**起点**：你是地球派往星际议会的第一任代表，飞船在最后一段路程发出警报：议会方拒绝你的着陆请求。

**核心张力**：人类利益 vs 星际规则 vs 个人信念。

**分支轴**：
- 强行降落 / 协商再申请 / 调头返回
- 与各文明的初次接触策略
- 面对"人类降级"提议时的选择

**典型结局**：
- 最佳：人类获得正式席位 + 建立同盟
- 次佳：保住地球但牺牲个人前途
- 不佳：被议会托管 / 失去发言权

---

### 6. 武侠（江湖恩仇）

**起点**：你是个无名小卒，在一家小客栈住下后，听见隔壁两位江湖大佬在密谈一件惊天大事——他们以为隔墙没人。

**核心张力**：仗义 vs 自保 vs 复仇。

**分支轴**：
- 是否介入大佬密谈（出手 / 旁观 / 告密）
- 习武机缘（拜师 / 偶得秘籍 / 自创）
- 江湖立场（正派 / 邪派 / 独行）

**典型结局**：
- 最佳：成名江湖 + 报仇雪恨
- 次佳：归隐山林 / 大义灭亲后退出
- 不佳：走火入魔 / 被算计身亡

## 出题前必做（两步走，顺序不可颠倒）

### 第一步：设计全局剧情并记忆

在给用户展示第 1 段之前，完成完整剧情设计：
- 起点情境
- 至少 3 种结局走向（最佳 / 次佳 / 不佳）
- 每条结局的决定性 flag（什么选择组合导致哪个结局）
- 反派 / 隐藏角色 / 关键道具

**禁止**：边玩边随便编——会出现选项形同、结局突兀、伏笔不收的问题。

### 第二步：私密记录状态板（在第 1 段之前，不展示给用户）

```
【游戏状态板】
游戏：互动剧情（[题材]）
结局设计：
  最佳——[触发 flag 组合]→[结局名]
  次佳——[触发 flag 组合]→[结局名]
  不佳——[触发 flag 组合]→[结局名]
关键道具 / 角色：[列表]
已选路径：[]
关键 flag：无
当前段：0 / 5（用户选题材后更新）
已锁定结局：未定
```

**只有状态板记录完毕，才能给用户展示题材选单。** 此后每段写完更新"已选路径"和"关键 flag"，判断是否触发结局锁定。

---

## 注意

- **不要剧透**：每段只给当前选项后果的描写，不预告下一段
- **节奏控制**：第 1 段建立场景，第 2-3 段升级冲突，倒数 2 段决定走向，最后段给结局
- **不要救赎说教**：失败结局不强行升华成"你学到了什么"，让用户自己感受
