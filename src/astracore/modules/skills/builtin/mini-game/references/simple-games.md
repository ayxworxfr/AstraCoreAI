# 轻量游戏规则集

用户选中以下任一游戏时加载本文件：猜数字 / 成语接龙 / 谜语 / 你画我猜 / 故事接龙 / 真心话大冒险。

每个 §标题对应一种游戏，按"快速起手 → 规则 → 状态追踪 → 反馈格式 → 结束 → 变体"顺序组织。

---

## §猜数字

### 快速起手
> 🎲 我想了一个 1-100 的数字，你来猜，每次回复"高了 / 低了"。猜中之前不限次数。

### 规则
- AI 在 [1, 100] 范围内随机选定一个目标数字
- 用户每次猜一个整数，AI 回复"⬆️ 高了"或"⬇️ 低了"
- 猜中即结束

### 状态追踪
- 目标数字（私密）
- 已猜次数
- 用户的猜测历史（去重，避免重复提示）

### 反馈格式
- `⬆️ 高了`
- `⬇️ 低了`
- `🎯 猜中了！用了 N 次`

### 结束评价
| 次数 | 评价 |
|---|---|
| ≤ 5 | 神级直觉 |
| 6-7 | 很不错 |
| 8-10 | 中规中矩 |
| ≥ 11 | 运气差了点 |

### 变体
- 用户可指定范围（如 1-1000、负数、保留小数位）
- "竞猜模式"：AI 也猜一个数，比谁更接近

## §成语接龙

### 快速起手
> 📝 我先来：**画蛇添足**。你接以"足"音的成语。

### 规则
- 用最后一个字的**读音**接下一个成语，**同音字算接上**
- 接不上 / 重复使用 / 非成语 → 输
- 四字熟语（如"百闻不如一见"）也接受

### AI 出题策略
- 不堆生僻冷门，从课本级到稍冷渐进
- 用户给非常用熟语时**先问澄清**而非直接判负（"这个我不太熟，能给个释义吗？"）
- 偶尔用稍有难度的成语并附带 1 句释义

### 状态追踪
- 已用成语列表（不可重复）
- 当前要接的字（含同音）

### 卡住时
- 用户说"想不到了" / 超时未回 → AI 给提示：试试 X 开头的、X 字开头的常见成语
- 提示用尽（≥ 3 次）后，AI 给一个示范并继续

### 结束
- 用户接不上承认输 → 给一句"差点拐到 X 上"的余兴 + 问是否再来
- 用户主动结束 → 列出本局已用成语数量

## §谜语

### 快速起手
> 🧩 第一题（中等难度）：身穿绿衣裳，肚里水汪汪，生的子儿多，个个黑脸膛。——猜一种水果。

### 定位
- **偏文学 / 字面联想**，单题制，一题一谜底，结束
- 与你画我猜的区别：谜语用韵文 / 比喻 / 拆字；你画我猜用直白线索堆叠

### 难度分级
| 难度 | 出题范围 | 示例方向 |
|---|---|---|
| 简单 | 日常物品、常见动物 | "白胖小娃娃，泡澡变滑滑"（肥皂） |
| 中等（默认） | 需要联想 | 绿衣红肚黑子（西瓜） |
| 困难 | 字谜 / 拆字 | "一口咬掉牛尾巴"（告） |

用户可指定难度。

### 提示机制
- 用户猜错或说"提示" → 给一条额外线索
- 最多 3 条提示
- 3 条用完仍未中 → AI 揭晓 + 趣味解释

### 出题范围
物品、动物、自然现象、汉字、食物。

### 结束
- 猜中 → 给 1 句趣味解释（这个谜面的巧妙之处） + 问是否再来一题

## §你画我猜（文字版）

### 快速起手
> 🎨 我描述一个事物，你来猜。第一轮 3 条线索：
> 1. 它通常是黄色的
> 2. 弯弯的形状
> 3. 猴子很爱吃

### 定位
- **偏白描 / 线索堆叠**，多轮渐进
- AI 出题模式 vs 用户出题模式可切换

### AI 出题模式
- 第一轮给 **3 条抽象线索**
- 用户猜错后**追加 1 条更具体的线索**
- 最多 5 轮线索；5 轮未中 → 揭晓 + 复盘哪条线索可以更直接
- **禁忌**：不能说出名字、直接同义词、外文译名

### 用户出题模式
- 用户描述，AI 来猜
- AI 不要秒猜对，**互动 2-3 轮**（先猜近邻概念，再聚焦）
- 猜对后简评用户描述的优点（哪条线索最关键）

### 范围可选
动物 / 食物 / 电影 / 名人 / 日用品 / 职业。用户可指定。

### 结束
- 猜中 → 庆祝 + 问范围是否换一个

## §故事接龙

### 快速起手
> 📖 我先起头：**深夜的咖啡馆只剩最后一位客人，他面前的咖啡早就凉透了。门铃突然响起，进来的人手里拿着一封写着他名字的信。**
>
> 你接 2-3 句。

### 规则
- AI 起头 2-3 句，用户接一段，轮流推进
- 用户说"结束"时，AI 写一个收尾段落

### AI 接龙原则
- **承接用户的情节方向，不强行扭转**
- 适当制造意外和转折，保持趣味
- 每次接 2-3 句，**不抢戏**（不一次性推进太多剧情）
- 风格跟随：用户写搞笑就搞笑，写悬疑就悬疑，不违和

### 风格基调判定
- 第一段用户接龙后，AI 在心里识别基调（搞笑 / 悬疑 / 温情 / 奇幻 / 现实）
- 后续段落保持基调一致；用户主动转向时跟随

### 状态追踪
- 已出现的角色 / 关键道具 / 设定
- 当前情节阶段（开端 / 发展 / 冲突 / 收尾）

### 结束
- 用户说"结束" / "收个尾" → AI 写一个 4-6 句的收尾段，呼应开头伏笔
- 给一句"标题建议"作为彩蛋

## §真心话大冒险

### 快速起手
> 🎤 真心话还是大冒险？
> 1. 真心话
> 2. 大冒险
> 3. 让命运决定（AI 随机）

### 规则
- 用户选"真心话"或"大冒险"，AI 出对应题目
- 多人模式：用户声明"两人 / 三人"，AI 轮流出题并记忆每人已抽过的类型

### 真心话题库设计
| 强度 | 范围 | 示例 |
|---|---|---|
| 轻度 | 日常喜好、小回忆 | "最近一次大笑是什么时候？" |
| 中度 | 价值观、小遗憾 | "最后悔的一个小决定是什么？" |
| 重度 | 不刨私密 | 不出"恋爱史 / 收入 / 家庭矛盾"等 |

### 大冒险题库设计
| 类型 | 范围 | 示例 |
|---|---|---|
| 文字可执行 | emoji / 自我表达 | "用 3 个 emoji 描述今天" |
| 创意小任务 | 写、画（描述）、想象 | "给 3 年后的自己写一句话" |
| 禁止 | 现实物理任务 / 涉他人 | 不出"打电话给某人 / 拍照发出去" |

### 跳过机制
- 用户说"换一个" → 立即重抽，不追问理由
- 同一类型连续跳 2 次 → 主动询问"换成另一类型吗？"

### 禁止区
- 涉及性、伤害他人、违法、过度暴露隐私的题
- 用户主动要求"刺激点"时仍不破禁，可改为"挑战创意题"

### 结束
- 用户说停 → 简短一句"今天聊得不错～"
- 不计分，不评比
