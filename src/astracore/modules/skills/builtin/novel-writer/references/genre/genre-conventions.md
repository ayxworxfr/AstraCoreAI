## §web-novel — 中文网文

### 核心原则
读者为爽而来。每次阅读体验必须给予正向反馈。拖沓、无意义的挫折、长时间压制主角而无释放——都会导致读者流失。

### 节奏设计
- **小爽点**：每 1000-2000 字一次，如一句漂亮的怼回去、一个小突破、意外获得认可
- **中爽点**：每章结尾或隔章，如击败挑衅者、完成阶段性目标
- **大爽点**：每个剧情弧终点，如复仇成功、突破瓶颈、逆袭打脸
- **悬念钩子**：每章结尾埋钩，让读者必须点下一章

### 常见子类型套路

**升级流 / 系统流**
- 金手指在第1章或第2章必须出现，越早越好
- 系统面板需要清晰展示（等级、属性、技能）
- 升级节奏：初期快（建立爽感）→ 中期放缓（拉长战斗体验）→ 后期跨越式
- 每次升级配合实际战斗或能力展示，避免数字空涨

**都市流**
- 身份反差是核心：低起点 + 隐藏实力 + 高人脉（或高潜力）
- 打脸节奏：挑衅 → 忍让 → 爆发 → 对方震惊，不超过2章完成一个循环
- 女性角色关系线推进需配合主线，不能喧宾夺主

**玄幻 / 修仙流**
- 世界规则在前3章内建立清晰（境界体系、修炼方式）
- 主角天赋设定：表面平庸 + 隐藏逆天，或直接天才但有致命弱点
- 门派/势力格局：主角所在势力初期偏弱，给成长空间

**时间线设计（修仙/玄幻专项）**
- **凡人阶段**：年龄是有效坐标，时间感与现实相近，可按主角实际起始年龄写出跨度
- **突破寿元门槛后**：改用"境界段落"计时，以修炼历程描述时间跨度而非绝对年龄；年龄数字降权，境界门槛升权
- **高境界阶段**：一个叙事段落可跨越数十乃至数百年，用相对时间标记（如"某战后第N年"、"某纪元"）而非主角岁数
- **结构建议**：卷结构的分割依据应是"境界跨度"，时间跨度说明节奏快慢即可，不必每卷都对齐一个精确年龄区间；越到后期越不应拘于绝对年龄

### 人物设计要点
- 主角：有明确目标驱动，不能莫名其妙，读者必须理解他/她为何这样做
- 反派：不能是纯工具人，至少有一个合理动机；强力反派需提前铺垫
- 配角：各有独立目标和判断，不只在主角需要时出现；鲜明的一两个特征让读者快速辨认

### 章节结构参考

**目标字数：2800-3800字。** 上限3800字——超了说明本章装了两件事，应拆成两章。低于2800字说明信息密度不足或场景渲染偷懒，回去补具体动作/感官/对白，不要凑字。

```
开场（200-400字）：场景建立或直接切入冲突
发展（2400-3000字）：事件推进，至少 1-2 个爽点（番茄密度每2000字一个）
章末（200-400字）：情绪高点 + 悬念钩子
```

## §literary — 文学小说

### 核心原则
文学小说的读者寻求的是认知拓展、情感共鸣和语言体验。情节是载体，不是目的。人物的内心真实性和主题深度是评价标准。

### 结构选择

**三幕式**
- 第一幕（25%）：建立世界和人物，植入核心矛盾，第一幕末触发事件
- 第二幕（50%）：矛盾升级，人物被迫改变，中点转折（价值观或处境的重大变化）
- 第三幕（25%）：高潮与解决，人物完成（或拒绝）成长，主题落地

**非线性结构**（适合意识流、多线叙事）
- 需要明确的锚点让读者定向（时间标记、视角切换规则、叙事层次）
- 碎片化叙事必须在整体上完整

### 人物设计要点
- **内在缺陷优先**：人物的外部困境必须映照内心问题，两者要相互驱动
- **成长弧的真实性**：改变必须有充分铺垫，不能突然顿悟；也可以是拒绝改变（悲剧弧）
- **次要人物**：每个重要配角都有自己的欲望和逻辑，不只是主角的镜子

### 主题处理
- 主题不能说教，必须通过事件和人物行为体现
- 结尾可以开放、模糊，但必须给读者留下可思考的东西
- 意象和象征需要在文中重复出现（至少3次）才能成立

### 语言要求
- 避免陈词滥调，尤其是情绪描写（"心如刀割"这类直接替换为具体感官细节）
- 场景描写需有选择性——选择最能承载情感或主题的细节
- 对话承担信息、性格、关系、潜台词四重功能，去除纯粹的信息对话

## §genre-fiction — 类型小说

### 核心原则
每种类型对读者有明确承诺（类型承诺），必须兑现。读者选择推理就要得到公平的谜题和合理的解答；选择言情就要得到情感满足的结局。违背类型承诺是最大的失误。

### 子类型结构

**推理**
- 核心承诺：公平谜题 + 逻辑自洽的解答
- 线索必须在揭晓前全部呈现给读者（不能用读者未见过的信息解谜）
- 结构：发现案件 → 调查/误导 → 中点反转 → 真相揭露 → 收尾
- 误导线索（red herrings）：至少2个，但必须有合理解释

**言情**
- 核心承诺：HEA（幸福永远）或 HFN（当下幸福），不能BE结局（除非明确标注虐文）
- 核心障碍：阻止两人在一起的原因必须充分，且来自人物内部（价值观冲突）而非外部误会
- 三幕情感线：相遇吸引 → 深入了解/冲突 → 危机分离 → 和好在一起
- 副线（友情、家庭、事业）不能压过主线情感

**科幻**
- 核心承诺：世界观的内部一致性；科技/设定必须自洽
- 建立"一个大假设"原则：核心设定可以违反现实，但其余推论必须基于这个假设严格推导
- 避免科技解决一切——科技带来的问题和人的选择才是故事
- 信息投放节奏：世界观细节分散在前1/3，不做集中说明（避免信息倾倒）

**悬疑/惊悚**
- 核心承诺：持续张力 + 威胁的真实感
- 张力维持技巧：倒计时、信息不对称（读者知道危险而主角不知）、可信威胁
- 主角不能愚蠢——其行为必须在当时信息下合理，否则读者出戏
- 节奏：张力积累 → 短暂释放 → 更高张力，不能一直高压

### 通用要点
- 在前3章内明确兑现类型承诺（让读者知道他们读的是什么）
- 类型惯例是读者期待，可以颠覆但不能无视——颠覆需要有意为之
