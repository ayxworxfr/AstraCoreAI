# 角色魅力塑造

写"主角光环""第一眼记住的人"和"读者愿意磕的角色"。
触发场景：核心角色首次出场、高光时刻、视角主动落到角色身上时。

> 与 `writing-craft.md` 的"容貌描写"互补：那一节解决"出场时不要堆砌"，本节解决"反复出现时如何持续强化记忆点"。

---

## 视觉签名（必做）

每个 5 章以上反复出场的角色，必须设计 **1 个不可替代的视觉锚点 + 1 个习惯动作**，并在每次该角色登场时至少触发其中一个。

### 视觉锚点的合格标准

- **唯一性**：脱离上下文也能反向定位到角色（"那个袖口沾着墨点的少年" → 只可能是某人）
- **可重复触发**：每次出场都自然带出来，不显刻意
- **承载信息**：不是装饰，是性格 / 经历 / 处境的外化

### 锚点类别（任选其一，建议混搭）

| 类别 | 示例 | 承载信息 |
|---|---|---|
| 标志性外貌 | 左眉一道淡疤、右手戴着发黑的银戒、永远有点湿的眼尾 | 经历 / 体质 |
| 标志性穿着 | 总穿一件领口磨白的旧军大衣、腰带上挂三只香囊 | 阶层 / 习性 |
| 标志性器物 | 不离手的铜烟枪、一柄缠着红绳的折扇、断了一角的玉佩 | 身份 / 故事钩子 |
| 标志性身体习惯 | 紧张时摸耳垂、笑前先抿一下嘴、走路右脚比左脚响半拍 | 性格底色 |
| 标志性气味 / 声音 | 身上常带一股冷柏木味、说话尾音爱拖一拍 | 神秘感 / 个性 |

### 反复触发的"轻量出现"模板

每次该角色登场（哪怕只露一面），从锚点池抽取 1 处，**用半句到一句带出**，绝不重新介绍：

- ✅ "陈三抹了一下袖口的墨点，没说话。"（墨点锚点 + 动作）
- ❌ "陈三今天还是穿着那件领口磨白的旧外套，袖口沾着墨点……"（出场重新介绍 = 啰嗦）

## 美貌 / 帅气的"隔山打牛"

**铁律：永远不正面写"美"或"帅"。** 形容词描写一次就免疫，第二次读者只会跳过。改用以下三条路径：

### 路径 1：他人反应

写**别人看到这个角色时的微反应**——比写脸本身有效十倍。

- ✅ "他抬眼看向街对面那位姑娘，端在手里的茶杯停了三秒。"
- ✅ "守门的兵看了她一眼，又看了一眼，然后忘了自己要喊什么。"
- ❌ "她长得非常漂亮，肤白貌美，眼睛像水一样。"

### 路径 2：环境衬托

让光线 / 环境 / 物件参与塑造，不直接写人。

- ✅ "她走过去的时候，廊下挂着的纱幔被风吹起，碰到她的肩膀，又顺着她的手臂滑下去。"
- ❌ "她身穿白纱，仙气飘飘。"

### 路径 3：碎片化局部

只写**一个具体的局部 + 它在做什么**，不做全景描写。

- ✅ "他低头看手里的信，眼睫在脸颊上投下两道短影。"
- ❌ "他剑眉星目，鼻梁高挺，嘴唇薄而坚毅。"

### 量化规则

- 同一角色"美 / 帅"主题描写，单章不超过 2 处
- 整本书禁止使用：**"绝美 / 倾国倾城 / 仿佛画中走出 / 不食人间烟火 / 玉树临风 / 剑眉星目"** 等套话
- 每次写美貌必须有**具体动作或具体局部**作为载体，不能只用形容词

## 性格魅力的"三件套"

让一个角色在读者心里活起来，最快的路径不是写性格分析，是给他三样东西：

### 1. 一句**反复出现的口头禅 / 句式**

不是真的"口头禅"——而是这个角色独有的说话习惯。

- 例：陈三紧张时第一句永远是"哎，您听我说啊——"
- 例：长安遇到逻辑漏洞会先沉默两秒然后说"等等"

**自检**：把对白里的署名删掉，老读者能不能凭这句话猜出是谁？能 → 合格。

### 2. 一个**只属于他的小怪癖**

- 例：方念念在思考时会用指尖在桌面上画看不见的环形
- 例：钱副阁主只用左手端茶，右手永远空着

每次紧张 / 思考 / 高光场景至少触发一次。

### 3. 一条**别人不知道的底色**

读者知道，但其他角色不一定知道——这是"看戏感"的来源。

- 例：长安前世猝死的恐慌偶尔在梦里出现
- 例：林小满表面活泼，每天晚上都要在院子里站半小时，望向北方

底色不必每章都写，但每 5-10 章应露一次"裂缝"，提醒读者它存在。

## 高光时刻的"杀手镜头"

角色出场如果是高光场景（首次亮相、关键反转、高光对决），开场前 3 句必须做到 2 项以上：

- [ ] **环境停顿**：周围声音 / 动作短暂凝固 1-2 秒
- [ ] **他人视线汇聚**：3 个以上人物的目光落在角色身上（量化）
- [ ] **细节特写**：角色的某一个具体局部被慢镜头放大（手指 / 眼睫 / 衣摆）
- [ ] **气味 / 声音先行**：角色还没正式出现，先有某种感官信号到达
- [ ] **对比衬托**：用一个"反差物"凸显角色（破衣服里露出的玉佩、烈日下的冷光）

## 禁止输出

| 禁止表述 | 替代 |
|---|---|
| "他长得非常英俊" / "她美若天仙" | 写他人反应 / 局部特写 / 环境衬托 |
| "气质不凡" / "卓尔不群" | 给一个具体的标志性动作或物件 |
| "剑眉星目 / 玉树临风 / 倾国倾城" | 写一个能让读者复述的具体特征（疤、戒、习惯） |
| 角色每次出场都重新描述外貌 | 用"轻量出现"模板：1 句话调用既有锚点 |
| 主角性格只靠旁白说"他是个 X 的人" | 用口头禅 + 怪癖 + 底色三件套展示 |

## 输出前自检（角色场景）

- [ ] 本章出现的核心角色，每人至少触发了 1 处视觉锚点或习惯动作
- [ ] 美貌 / 帅气描写没有出现"绝美 / 玉树临风"等套话
- [ ] 美貌描写若出现，是否使用了"他人反应 / 环境衬托 / 局部特写"中的至少一种
- [ ] 高光出场是否触发了"杀手镜头"清单中至少 2 项
- [ ] 角色没有重新介绍既有外貌（避免出场即流水账）
