# 多视角调度

只跟主角一条线 = 流水账。读者看见的世界永远等于主角看见的世界，没有信息差，就没有张力。

> 与 `writing-craft.md` 的"场景切换与副线"互补：那一节给原则，本节给量化配额、触发条件和具体过渡句法。

---

## 配额（铁律）

### 卷级配额

- **每 5 章至少 1 个非主角视角的独立场景**（300-1500 字均可）
- **本卷的 BOSS 反派 / 对手必须有至少 3 个独立视角场景**（出现 → 谋划 → 失败时的破防）
- **本卷有 2 个以上核心配角的，每人至少 1 个独立视角场景**

### 战斗专用配额

- 任何"持续超过 1 章" 或 "决定本卷走向" 的战斗，必须切至少 1 次非主角视角
- 单章战斗也建议切 1 次（让对手或旁观者承担反应）

### 写不出来时

如果发现"想不出能切给谁"，说明本卷反派 / 配角设计太薄。回到 `novel-framework.md` 和 `novel-characters.md` 补强他们的独立目标和当下行动。**绝不允许**用"主角推断对方应该在做什么"代替直接的反派视角场景。

---

## 切视角的触发条件

满足以下任一条件，**必须**切非主角视角：

| 触发 | 例子 |
|---|---|
| 危险正在逼近，主角不知情 | 反派在远处布置陷阱、追杀者已上路 |
| 对手即将出场，需要先建立威胁感 | 下一章主角要遇到 BOSS，本章先用半场展示 BOSS 的可怕 |
| 配角遭遇足以改变关系的事件 | 配角被人威胁但没告诉主角，自己处理 |
| 关键事件的真相只有反派知道 | 谁是凶手 / 阴谋的源头 |
| 主角的高光场景需要被"见证" | 主角立功后，反派 / 高层听到消息时的反应（爽点扩散） |
| 反派失败时的"破防" | 详见 `climax-design.md` |

## 切镜头的标准句法

### 全知视角（默认网文）

直接用过场标志，不需要解释：

```
———

千里之外，黑石城。
```

或

```
与此同时，在城西的酒楼三楼。
```

或

```
就在他闭上眼的那一刻，无极仙宗后山，那一道沉睡的光芒又跳动了一下。
```

### 限制视角（少见，文学倾向）

需要更软的过渡，避免破坏主角视角的沉浸：

- 用"消息"作为切换点：让主角接到一封信 / 听到一句传闻 / 看到一份卷宗，然后回叙真相
- 用"梦境 / 灵识 / 神识扫过"作为视角扩展手段（修真题材常用）
- 章节标题直接换人物名字，新一章另起视角

## 反派视角的写法

反派视角不是"反派内心独白告诉读者他要做坏事"。那是廉价的恶趣味。合格的反派视角必须做到三件事：

### 1. 让反派"自洽"

反派眼里他自己不是反派。从他的逻辑出发，他的选择有合理动机：

- ✅ "李正源把信纸放进炉里。火舌舔上去的瞬间，他想起十二年前那场水患——若不是当时被那位许大人压下了一手，岭北饿死的就不止三万人。**今日他只是把当年欠的账要回来。**"
- ❌ "李正源阴险地笑了笑：'许长安，你死定了！'"

### 2. 给反派"具体动作"

反派视角必须落到他正在做的具体事上，不是只展示他的内心。

- ✅ "他用左手抚过案上那柄断剑——剑刃缺了一角，是十二年前那一战留下的。然后他抬头，对站在帘外的人说：'去告诉东厂的萧公公，我要见他。'"
- ❌ "他在心里盘算着如何对付主角……"

### 3. 让反派看到的世界**与主角看到的不同**

读者读反派视角不是为了"再听一遍主角的事"。要让读者发现：原来这件事在反派眼里是这样的。

- 主角以为自己藏得很好 → 反派视角里，主角的每一步都被看穿
- 主角以为反派强大 → 反派视角里，反派也在恐惧某个更大的东西
- 主角以为某事是巧合 → 反派视角里，那是精心设计

## 信息差的三种用法

切了反派视角后，读者比主角多了信息。这个信息差必须用起来——否则切视角白切。

| 用法 | 效果 |
|---|---|
| **延迟揭示** | 读者已知陷阱，看主角一步步走进去，制造代入式紧张 |
| **错位喜剧** | 读者已知反派的误判，看反派以为自己赢了实际在送，制造爽感 |
| **预期反转** | 读者以为知道全貌，最后揭示反派也只是棋子，制造惊讶 |

## 切镜头的"回响"原则

每一个独立场景必须**最终与主线交叉**——否则它是浪费篇幅。

切镜头时心里就要规划好：

- 这个场景里发生的事，会在第几章影响主角？
- 反派此刻的决定，会在何时让主角感受到？
- 配角此刻的秘密，会在什么节点被主角发现？

如果想不出回响章节，**这一镜头不要切**。

---

## 旁观者视角的轻量用法

不一定每次切视角都要写一整个独立场景。一段战斗 / 一个高光时刻里，**穿插 2-3 句旁观者镜头**就能极大提升张力：

```
[主角的动作] →
[换行：看台上某长老的一句话 / 某弟子手里掉了一支笔 / 远处贵宾区茶杯停在嘴边] →
[主角的下一个动作]
```

这是"半切镜头"——视角没真的离开主角，但把读者的注意力短暂引向他人的反应。每场重要战斗都该用 2-3 次。

## 禁止输出

| 禁止 | 替代 |
|---|---|
| 整卷只有主角视角 | 至少 5 章一次切镜头，反派至少 3 次独立场景 |
| 反派视角只有内心独白没有动作 | 必须落到他正在做的具体事上 |
| 反派内心说"我要害死主角！" 式的脸谱化 | 让反派从他自己的逻辑出发自洽 |
| 切镜头的场景与主线永远不交叉 | 切之前规划好"回响章节" |
| 用"主角推测对手在做什么" 代替直接的反派视角 | 反派的事直接写反派 |
| 战斗全程主角视角，旁观者只有 1-2 句 | 重要战斗至少切 1 次完整非主角视角 |

## 输出前自检（多视角）

- [ ] 本章如有重要战斗 / 高光场景，是否切了至少 1 次非主角视角（哪怕只是 2-3 句旁观者特写）
- [ ] 当卷视角配额：距上一次非主角独立场景已经多少章？≥ 5 必须本章或下章插入
- [ ] 本章如有反派视角，是否做到三件事（自洽 / 具体动作 / 视角不同）
- [ ] 切镜头的场景，是否已规划与主线的交叉点（"回响"章节）
- [ ] 没有用"主角推测"代替直接的反派视角场景
