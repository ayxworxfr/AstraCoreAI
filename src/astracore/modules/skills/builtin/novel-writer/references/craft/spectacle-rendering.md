# 能力 / 招式 / 战斗特效渲染

打架不能像"我打你一下你打我一下"。能力展示是网文最大的爽点载体之一，必须按规范渲染。

触发场景：战斗、施法、能力展示、宝物激活、阵法启动、跨等级压制、首次展示一项新能力。

---

## 四段式渲染（铁律）

任何一个**有名字的招式 / 能力 / 法术**首次展开时，必须四段齐全。重复出现时可压缩到二段。

| 段位 | 长度 | 必含元素 |
|---|---|---|
| **起势** | 2-4 句 | 角色身上的细微变化（呼吸 / 眼神 / 灵气波动）；环境的预感性反应（风停 / 灯火乱 / 动物逃窜） |
| **蓄力** | 2-3 句 | 力量积聚的可视化（颜色 / 形态 / 几何形）；对手或观众的反应（一声"不好"、退后、抬手挡） |
| **爆发** | 3-6 句 | 多感官层叠（见下文）；招式名称喊出（若有）；对手承受的瞬间画面 |
| **余波** | 2-4 句 | 环境破坏锚点（地面、空气、远处建筑）；人物状态（伤势 / 力竭 / 站立姿态）；旁观者反应 |

### 反模板（流水账打斗）

```
六股灵气从她指尖射出，朝周明远飞去。周明远被击中，倒在地上。
```

四段齐全后改写：

```
方念念食指与中指相抵，指尖六点细芒同时亮起——亮得不刺眼，反而像是把
周围的灯火都吸了一吸。【起势】

那六点芒光开始绕着她的指尖旋转，越转越快，最后融成一道环状的银线。
台下有人下意识屏住了呼吸。【蓄力】

银线骤然撕开！六道丝光分六个角度切入战场，没有打在周明远的护体灵气上，
而是从他身后合拢——像六根被无形之手抛出的针，精准穿过他的灵脉穴位
外侧，编成一张几乎看不见的网。周明远低头的瞬间，身上的藤蔓灵气已经
开始断流。【爆发】

擂台青石上没有半点裂痕——没必要裂——但周明远膝下三尺的灰尘安静
地、整齐地向外推开了一圈。看台前排有位长老缓缓放下手里的茶盏，
没有再端起来。【余波】
```

## 多感官层叠规则

爆发段必须包含**至少 3 种感官**。**只有视觉 = 流水账**。

| 感官 | 写法举例 |
|---|---|
| 视觉 | 颜色 / 形状 / 速度 / 光影变化 |
| 听觉 | 招式音效（嗡 / 裂帛声 / 闷响 / 像是远处闷雷）、对手发出的声音、环境的声音骤变 |
| 触觉 / 体感 | 空气被推开的压力、温度骤变（冷 / 灼）、皮肤的麻意 / 刺痛 |
| 嗅觉 | 焦味 / 血腥 / 灵气产生的特殊气味（如剑气有金属冷香） |
| 时间感 | "这一瞬被拉得很长" / "三个呼吸过去了" / "比心跳还快" |

## 力量锚点（量化标尺）

无形的力量必须落到有形的破坏上。读者通过破坏程度反推力量等级。

### 锚点选择（按力量等级递增）

| 等级 | 锚点 |
|---|---|
| 初级 | 衣摆被掀起 / 灰尘被推开一圈 / 旁边茶水起涟漪 |
| 中级 | 地面出现裂痕 / 树叶哗哗作响 / 三步内的人下意识后退 |
| 高级 | 石板崩开一条缝 / 空气出现可见的扭曲 / 远处的瓦片震落 |
| 顶级 | 半边广场凹陷 / 远处一座塔的顶尖断了 / 数百米外的湖水倒映出涟漪 |
| 灭世 | 地形被改变 / 天象异变 / 千里外能看见这一击 |

### 铁律

- 同一招式，**力量锚点必须与角色当前实力匹配**——不要写到一半突然跨等级（除非剧情就是要展示"突破"）
- 同一战斗内，锚点描写**不可全部集中在最后**：每一回合至少给一个小锚点（涟漪 / 灰尘 / 衣摆），最大锚点留给关键一击
- 跨等级碾压时，把锚点放到**对手身上和对手周围**：地面没事，但对手脚下凹了；周围观众没事，但近处三个人腿软了

## 招式喊招的渲染脚本

招式有名字时，按以下结构调用：

```
[蓄力 1-2 句] →
[喊出招式名（独立一句或上引号）] →
[爆发画面 + 对手承受] →
[环境锚点 + 旁观者反应]
```

### 注意

- **招式名要响**：四字 / 二字短语，避免拗口（"赤龙啸""寒星诀""万剑归宗"，不要"火焰极速旋转之刃术"）
- **不是每一招都要喊**：高频出现的常用招式只在关键场景喊；常规出招用动作描写一句带过
- **同一战斗喊招上限 3 次**：超过就疲劳，读者会跳过

## 同级 vs 跨级对决

两套写法不能混用。

### 同级对决（势均力敌）

- 节奏：**多回合 / 来回攻防 / 互相试探**
- 重点：策略、招式克制、心理博弈
- 视角调度：**主角视角 + 至少 1 次对手内心 OS**（让读者看到"对手以为自己赢了的瞬间"）
- 转折点：找到对方破绽 / 一招逆转 / 引诱对方进入自己节奏

### 跨级碾压（强对弱）

- 节奏：**短 / 突然 / 一招定胜负 / 对方完全没反应过来**
- 重点：**对手的恐惧 + 旁观者的震撼**，主角动作可以极度克制
- 视角调度：**主视角放在被碾压的一方** —— 读者从对方眼里看主角"如鬼似神"
- 写法：避免主角心理描写，让威压和反应做完所有工作

### 跨级碾压模板

```
[对手准备的全部动作 ——花 1 段铺] →
[主角一个简单动作（抬手 / 伸指 / 看一眼）] →
[对手的世界被打断（招式散了 / 飞出去 / 跪下）] →
[1 拍空白时间] →
[旁观者的吸气声 / 动作停止 / 兵器掉地的声音]
```

## 多视角调度（战斗专用）

战斗中不要只锁主角视角。每场重要战斗至少切换 1 次视角：

- **对手内心**：他在想什么、他以为发生了什么、他的判断错在哪
- **旁观者**：他们看到的是什么、他们的解读是否与真实不同
- **远处第三方**：某个高人 / 某个反派远远看到这场战斗，他的反应

详细切镜头规则见 `multi-pov.md`。

## 禁止输出

| 禁止表述 | 替代 |
|---|---|
| "X 招式飞出 / 击中 Y / Y 倒在地上" 三句结束一场战斗 | 至少四段渲染 |
| 招式描述只有视觉一种感官 | 至少 3 种感官层叠 |
| "无比强大" / "威力惊人" / "霸气十足" | 用力量锚点替代——给读者一个能反推力量的具体破坏 |
| 整场战斗主角内心独白超过 1 段连续 | 拆开，让对手 / 旁观者承担一部分视角 |
| 同一战斗喊出招式名 ≥ 4 次 | 控制在 3 次以内 |
| 招式名长 / 拗口（"九转混元七彩升天大法之一式"） | 改为 2-4 字短名 |
| 跨级碾压时还在写主角动作分解 | 让威压和反应做事，主角动作越简单越好 |

## 输出前自检（战斗 / 能力场景）

- [ ] 至少一处招式 / 能力的渲染包含**起势 / 蓄力 / 爆发 / 余波**四段
- [ ] 爆发段是否调动了 ≥ 3 种感官（不能全是视觉）
- [ ] 是否给出了至少一处具体的"力量锚点"（地面 / 空气 / 旁观者反应）作为力量量化
- [ ] 力量锚点的等级是否与角色当前实力匹配（没有越级）
- [ ] 是否切了至少 1 次非主角视角（对手内心 OS / 旁观者反应）
- [ ] 招式名（如有）数量 ≤ 3，且都是 2-4 字短名
- [ ] 跨级对决是否做到"主角动作克制 + 对手 / 旁观者承担反应"
