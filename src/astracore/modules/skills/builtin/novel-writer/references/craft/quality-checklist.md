# 质量清单

写完章节后依次执行三层检查。发现问题立即修正，不记录为"待修"再继续。

---

## 第一层：一致性

对照 `novel-state.md` 的 Key Continuity Notes 和状态文件：

- [ ] 所有固有名词（人名/地名/宗门名/道具名/具体数字）与 Key Continuity Notes 一致
- [ ] 人物行为符合 `novel-characters.md` 中的性格与成长弧
- [ ] 情节符合 `novel-framework.md` 中的弧线规划
- [ ] 散文风格符合 `novel-style.md` 中的 POV、时态、语气定义
- [ ] 本章新出现的信息（新设定/新伏笔/人物新承诺）已准备追加到 Key Continuity Notes

---

## 第二层：写作质量

调用 `get_skill_reference("禁用词表")` 扫描全文：

- [ ] 无一级禁用词
- [ ] 二级禁用词在本章出现次数 ≤ 1
- [ ] **统计全文 `——` 总数，写出具体数字**（如"本章 `——` 共 X 处"）；数量 > 5 时**必须删减至 ≤ 5 再继续**，不得跳过此项
- [ ] **零容忍：对话末尾 `——`**——grep 全文，凡是匹配 `——"` 或 `——」` 模式（破折号紧接对话引号收尾）的悬停式用法，必须全部改写（写完话 / 改 `……` / 用动作接住）。哪怕本章 `——` 总数 ≤ 5，只要存在此模式就回去改
- [ ] 每个重要情绪节点有具体的神情或肢体细节，无"他很紧张/她很伤心"式直接陈述
- [ ] 连续内心推断不超过三句——**每三句推断之后有感官细节，不是推断链结束后才落地**
- [ ] 若有数字计算或逐条列举（"一，……二，……三，……"式），每条之后插入了感官细节
- [ ] 若有"走路+思考"段落，每隔三句推断有至少一处环境或肢体细节
- [ ] 每个名字出现超过三次的配角，本章有超出"回答主角问题"的独立动作或判断

---

## 第三层：章节结构

- [ ] 章节开头前 200 字有情境切入点，而非纯背景交代
- [ ] 章节内有至少一处"慢"段落（感官细节/人物发呆/无关小动作）
- [ ] 章节结尾有情绪收束或悬念——决意型、悬念型、情绪型之一
- [ ] 章节标题：不连续三章全为 2 字；同卷 2 字标题占比 ≤ 1/3
- [ ] 若本卷核心配角本章未出场，回顾：上一次他们有独立行动（非"告知主角"）是哪章？超过 5 章未出现独立视角则需规划插入时机

---

## 第四层：高光场景专项检查（条件触发）

**触发条件**：本章包含战斗 / 招式展示 / 重要角色高光 / 立威 / 打脸 / 反转 / BOSS 出场 中任何一项。
不触发则跳过本层；触发则**全部检查项必须通过**，否则回去改写。

### 角色魅力（出现核心角色场景时）

- [ ] 本章出现的核心角色，每人至少触发了 1 处视觉锚点或习惯动作（见 `character-charisma.md`）
- [ ] 美貌 / 帅气描写没有出现"绝美 / 玉树临风 / 倾国倾城 / 剑眉星目 / 仙气飘飘"等套话
- [ ] 美貌 / 帅气描写若出现，使用了"他人反应 / 环境衬托 / 局部特写"中至少一种，没有正面写"美"
- [ ] 高光出场是否触发了"杀手镜头"清单中至少 2 项（环境停顿 / 视线汇聚 / 局部特写 / 气味声音先行 / 反差衬托）

### 特效渲染（战斗 / 招式 / 能力展示场景）

- [ ] 至少一处招式 / 能力展示包含**起势 / 蓄力 / 爆发 / 余波**四段（见 `spectacle-rendering.md`）
- [ ] 爆发段调动了 ≥ 3 种感官（不能全部是视觉）
- [ ] 给出了至少一处具体的"力量锚点"作为力量量化（地面 / 空气 / 旁观者反应 / 远处动静）
- [ ] 力量锚点等级与角色当前实力匹配（无越级渲染）
- [ ] 招式名（如有）数量 ≤ 3，且都是 2-4 字短名
- [ ] 跨级对决场景：主角动作克制 + 让对手 / 旁观者承担反应（不堆主角心理独白）

### 多视角（重要对抗 / BOSS 谋划）

- [ ] 本章持续超过半章的对抗，是否切了至少 1 次非主角视角（即便只是 2-3 句旁观者特写）
- [ ] 距上一次非主角独立场景 ≥ 5 章 → 本章或下章必须插入
- [ ] 反派视角（如有）三件套是否齐：自洽动机 / 具体动作 / 视角与主角不同
- [ ] 切镜头的场景是否已规划与主线交叉的"回响"章节
- [ ] 没有用"主角推测对方应该在做什么" 替代直接的反派视角

### 爽点（高光 / 立威 / 打脸 / 反转）

- [ ] 五段爽点公式（低估 / 克制 / 爆发 / 破防 / 涟漪）至少完成 4 段（见 `climax-design.md`）
- [ ] 段 1"低估" 在前 3-5 章是否有铺垫
- [ ] 段 4 反派破防是否给了具体动作（不是直接说"他破防了 / 不敢相信"）
- [ ] 段 5 涟漪扩散是否覆盖近 / 中 / 远三层中至少 2 层
- [ ] 群众反应是否按强度分级（不重复使用同一种描写）
- [ ] 同一反派是否已连续破防 ≥ 2 次 → 本次起需升级或更换反派
