# 禁用词表

对照此表检查章节文本。**一级词**命中即替换；**二级词**在同一章出现 2 次以上时替换。

---

## 一级禁用词（出现即替换）

### 情态类
仿佛、犹如、宛若、好似、一丝、一抹、些许、几分、隐约

### 动作类
深吸一口气、缓缓、不禁、微微、轻轻、淡淡

### 表情类（模板化用法）
眼中闪过、嘴角勾起、眉头微皱、眉眼低垂、瞳孔微缩

> 以上表情词描述的是真实反应时不受限，受限的是用它们代替具体细节的模板用法：
> ❌ "眼中闪过一丝不易察觉的悲伤" → ✅ "他垂下眼"

### 心理类
心中一动、心头一震、心下了然、心中暗道、心底泛起、不由得

### 判断类
不容置疑、显而易见、毫无疑问、不可否认、不易察觉

### 场景氛围类（AI高频滥用）
触发条件：以人影为主体、无具体物陪衬，单独撑氛围
❌ "夕阳把他的影子拉得很长" / "阳光把他的影子拉得很长"
✅ "夕阳把石榴树的影子拉得很长，小果子在风中晃动"——有具体物，不触发
判断标准：影子句后面有没有具体的物体或动作接住。有就放行，没有就替换成光落在某个具体物体上，或直接切人物动作。

## 二级禁用词（同章出现 2 次以上时替换）

### 对话标签
"说道""问道""笑道"——连续三句对话以上出现时，改用动作引出或省略标签

### 升华句式（章尾/段尾）
"这一刻"、"他终于明白"、"她这才意识到"、"原来……"、"一切……都……"

### 连续排比
三句以上相同句式结构——保留最强一句，删掉其余

### 总结收尾
"他知道……""她明白……""这就是……"用于段落收尾时

## 标点符号约束

### 破折号 `——` 硬性数量限制

**每章不超过 5 处**。自检时统计全文 `——` 数量，超出即削减。

**合法用途（仅以下三种）：**

| 用途 | 示例 |
|------|------|
| 对话被打断、戛然而止 | `"我不——"她闭上了嘴。` |
| 叙事节奏急转，前后语义跳跃大 | `他推开门——里面没有人。` |
| 强调性插入（逗号撑不住时） | `这件事——只有他知道——不能说。` |

**高频滥用模式（立即替换）：**

| 错误用法 | 问题 | 替换方向 |
|---------|------|---------|
| `一根红色的绸带——天玄宗的标志。` | 用破折号做注解，句号/逗号即可 | `一根红色的绸带，天玄宗的标志。` |
| `这是个问题——灵气传导不稳定。` | 用破折号连接因果/解释 | 拆成两句，或改为逗号 |
| `他没有时间了——说完便转身离开。` | 用破折号衔接动作 | 改为句号，另起动作句 |
| `她看着他——眼神复杂。` | 破折号加注表情，模板化 | 直接写行为，删掉破折号 |
| `"我没有能力做灵气浓度检测。但是——"` | **对话末尾用 `——` 表示欲言又止 / 话没说完——绝对禁止**。读者只看到一个悬空的破折号，节奏被切断 | ① 把没说完的话直接写完；② 改成 `……`；③ 用动作接住：`"但是。"他没再往下说，转身看向窗外。` |
| `"那个人是——"他犹豫了一下。` | 同上，对话内 `——` 当省略号用 | 改 `……` 或断句后加描写 |

## 替换策略速查

| 原文 | 问题 | 替换方向 |
|------|------|---------|
| 深吸一口气 | 无意义动作，90% 可删 | 删掉，或换"胸口起伏了一下" |
| 眼中闪过一丝悲伤 | 模板化，告诉而非展示 | "他垂下眼" / 具体动作 |
| 嘴角勾起一抹冷笑 | 模板化 | "他笑了一下，没到眼底" |
| 仿佛能穿透一切 | 文言腔，空泛 | 直接白描，删掉比喻 |
| 他感到一阵紧张 | 直接陈述情绪 | "他的手在抖" |
| 她不禁红了眼眶 | 告诉 + 禁用词 | "她转过身去，肩膀微微颤动" |
| 这一刻，他终于明白 | 总结升华，AI标配 | 删掉，用之后的动作代替 |
| 她意识到事情不对 | 直接告知认知 | 用行为展示：她停下脚步 |
| 他说道 / 她问道 | 机械对话标签 | 用前后动作替代，或直接省略 |
| 微微点头 / 轻轻叹气 | 动作类禁用词 + 废话动作 | 给具体幅度，或删掉 |
