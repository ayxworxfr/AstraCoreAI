# 爽点设计 / 反派破防

爽点不是"主角赢了"，是"读者跟着主角一起爽"。
爽不爽，看的不是结果，是**铺垫深度 + 反差落差 + 涟漪扩散**。

触发场景：高光时刻、关键反转、首次展示某能力、打脸场景、立威立功场景。

---

## 爽点公式（五段结构）

任何一次"爽点"必须按以下五段铺：

```
[低估 / 蔑视 / 被否定]                ← 段 1：抬高反差
       ↓
[主角的克制 / 沉默 / 不解释]           ← 段 2：积蓄势能
       ↓
[出手 / 揭示 / 反转]                  ← 段 3：爆发瞬间
       ↓
[反派 / 否定者破防]                   ← 段 4：落差兑现
       ↓
[消息扩散 / 旁观者反应 / 余波传播]     ← 段 5：涟漪扩散
```

**少哪一段就少哪一份爽。** 反过来：缺第 5 段是网文最常见的丢分点——很多 AI 写完就停在"反派愣住"那里。

### 反模板

```
反派：你这个废物！
主角：[出手] [反派倒下]
[结束]
```

完整模板：

```
[反派 / 旁人冷笑：他没有灵根，根本上不了台]               ← 1
[主角站上擂台，没有解释，没有反驳，只是把头发别到耳后]      ← 2
[出招：八根灵气丝穿过藤蔓 / 锁喉 / 力竭]                  ← 3
[反派跪在地上。他抬头看着这个安静的女孩，嘴唇动了动，
 最终什么都没说]                                       ← 4
[第七层贵宾区，钱副阁主的茶杯停在嘴边，很久没有放下；
 后山一道沉睡的光芒颤动了一下；隔日早晨，整座青阳城都在
 议论"无极仙宗那个无灵根的女弟子"]                       ← 5
```

## 五段质量标准

### 段 1：抬高反差（低估 / 否定）

- 反差值 = 爽感上限。被低估得越彻底，反转时越爽
- 必须有**具体台词或具体行动**：不能只写"周围人鄙视他"，要给一句听得见的鄙视
- **配额**：连续 3 次以上的低估铺垫效果最佳；高光场景前 3-5 章的"埋线"是合格爽文的基本功

### 段 2：克制（沉默 / 不解释）

- 主角面对低估**不当场反驳**——读者代入感强烈：他们替主角憋着这口气
- 主角可以表面平淡 / 调侃 / 转移话题，但不解释自己实际多强
- **铁律**：主角的"克制"必须有内心 OS（半句即可）让读者知道他在憋——否则读者以为他真的就是怂

### 段 3：爆发（出手 / 揭示）

- 用 `spectacle-rendering.md` 的四段渲染法
- 爆发的"形式"应该**反差对应段 1**：被骂"废物"→ 一招制敌；被嘲"穷酸"→ 拿出豪奢；被轻"无背景"→ 露出顶级靠山
- 招式 / 揭示**最好出乎意料**：不是更强的同类（你强、我比你更强），是另一个维度（你练藤蔓，我直接锁你穴位）

### 段 4：反派破防（落差兑现）

爽点的"兑现"环节。反派不能只输——必须**破防**。

破防的层级（从浅到深）：

| 层级 | 表现 | 适用 |
|---|---|---|
| 1 - 愣住 | 表情凝固、动作停下、说不出话 | 小冲突 |
| 2 - 失态 | 怒吼、踉跄、东西掉地上、呼吸乱 | 中冲突 |
| 3 - 心理崩塌 | 自我怀疑、回想、试图找借口、回避眼神 | 重大对决 |
| 4 - 公开难堪 | 在他重视的人面前丢脸、跪下、求饶 | 反派彻底败 |
| 5 - 三观重塑 | "原来这世界不是我以为的样子" | 终局 BOSS |

破防描写**必须给具体动作**，不能只说"他破防了"：

- ✅ "周明远单膝跪地，他抬头看着面前这个安静的女孩，嘴唇动了动，最终什么都没说。"
- ✅ "李正源端着茶杯的手抖了一下，茶水溅在桌上他没去擦。"
- ❌ "李正源破防了，他无法相信自己的眼睛。"

### 段 5：涟漪扩散（必做，最易丢）

胜利后的**消息扩散**才是爽点真正落地的地方。完整涟漪应包含 3 层：

| 圈层 | 描写对象 | 长度 |
|---|---|---|
| 近场 | 战斗现场的旁观者：议论、震撼、有人站起、贵宾区有人放下茶杯 | 2-4 句 |
| 中场 | 同门 / 师长 / 对立宗门的反应：消息传到他们耳里时的瞬间反应 | 1 段（可切镜头） |
| 远场 | 顶层势力 / 远方反派 / 主角不知道的人：一句"有意思"或一个动作 | 1-3 句（钩子，下一卷可用） |

涟漪扩散可以分散在**胜利当章 + 后续 1-2 章**，不必全部塞在同一处。

## 落差公式

不是每个高光都要"爽"。有时"扬抑结合"更动人。三种节奏：

| 节奏 | 走向 | 适用场景 |
|---|---|---|
| **平地起惊雷** | 低 → 极高 | 立威 / 反杀 / 打脸 |
| **先扬后抑** | 高 → 略低（甚至代价） | 主角胜利但付出代价；展现成长但留隐患 |
| **抑扬并行** | 内圈高 + 外圈低（或反之） | 主角内心受挫但外人觉得他赢了 / 反之 |

整本书 100% 都是"平地起惊雷"会读疲。重要爽点用第一种，中段穿插二三种调味。

## 群众反应模板（按强度）

避免每次都写"周围人议论纷纷"。按强度分级：

### 低强度（小爽点）

- "看台上有人小声说了句什么。"
- "他身边的人对视了一眼。"
- "几道目光不约而同地从主角身上扫过。"

### 中强度（中爽点）

- 1-2 句具体台词："不可能……他刚才那一招是怎么做到的？"
- 一个具体动作：站起来、放下茶杯、笔停了、退后半步
- 群体反应：等候区一阵沉默 / 一阵骚动

### 高强度（重大爽点）

- **沉默先于议论**：不是立刻爆发，而是先有 5 秒钟的死寂，然后声音才像潮水一样涌来
- 关键人物的反应被特写（如长老 / 高阶贵宾 / 平时不动声色的人）
- 视角短暂切换到第三方："第七层贵宾区，钱广的茶杯停在嘴边，很久没有放下"
- **两段叙述**：①现场的反应 ②消息传出去后的反应

## 爽点节奏配额

### 章级配额

- 黄金三章每章必须 1 个小爽点
- 卷一第 4-10 章每章 1 小爽点 + 每 3 章 1 中爽点
- 卷一中后段：每 5-8 章 1 大爽点（完整五段）
- 全卷必须有 1-2 个"封神级"大爽点（涟漪扩散到下一卷）

### 反派配额

- 每卷至少破防 1 个有名有姓的反派（不是路人）
- 终卷 BOSS 的破防必须达到层级 4-5
- 同一反派不要连续被破防超过 2 次（破不了第三次的防 = 反派塌了）

## 禁止输出

| 禁止 | 替代 |
|---|---|
| 主角赢了就结束本场，没有反派反应、没有旁观者、没有消息扩散 | 必须有段 4 + 段 5；至少各 2 句 |
| 反派只输招式不破防 | 给具体的破防动作（嘴唇动了 / 茶杯停了 / 跪下） |
| "他破防了" / "他无法接受" 直接陈述 | 用具体动作或失态的细节 |
| 主角立功后立刻进入下一个剧情，不留余韵 | 至少给 3-5 句涟漪扩散 |
| 爽点没有事先铺垫"低估" 段，直接出手 | 高光前 3-5 章必须埋"低估线" |
| 主角面对挑衅时立刻反驳解释 | 段 2 的克制：先沉默或调侃，让势能积蓄 |
| 同一反派连续破防超过 2 次 | 第三次起反派必须升级或被替换 |
| 全卷无封神级大爽点 | 至少 1-2 个完整五段，且涟漪扩散到下一卷 |

## 输出前自检（高光场景）

- [ ] 本章是否包含设计的爽点？如是，是否五段齐全（段 5 涟漪扩散最易丢）
- [ ] 段 1 的"低估"在前 3-5 章是否有铺垫
- [ ] 段 2 主角是否克制（不当场反驳）
- [ ] 段 3 的爆发是否调用了 `spectacle-rendering.md` 的四段渲染
- [ ] 段 4 反派破防是否给了具体动作（不是直接说"他破防了"）
- [ ] 段 5 涟漪扩散是否覆盖近 / 中 / 远三层中至少 2 层
- [ ] 群众反应是否按强度分级（不重复使用同一种描写）
- [ ] 本卷至今的爽点节奏：小 / 中 / 大爽点配比是否健康
- [ ] 同一反派是否已连续破防 ≥ 2 次（如是，本次起需升级或换反派）
